# Getting help

- **How do I …?** Start with the [documentation](docs/README.md): the [CLI reference](docs/cli-reference.md), every
  [setting](docs/configuration.md), [the panel](docs/panel.md), [data and sync](docs/data-and-sync.md).
- **Something is not set up:** `bhote setup --json` shows what is missing; `/bhote-install` in Claude Code repairs it.
  See *Troubleshooting* in the [README](README.md#troubleshooting).
- **A bug:** open an [issue](https://github.com/floriankappert/bhote/issues/new/choose) with the bug report form.
- **An idea or a question:** open an issue with the feature request form, or ask in a plain issue.
- **A security problem:** see [SECURITY.md](SECURITY.md), never a public issue.
